# 紧急救援模拟训练营

面向小学生的安全应急互动学习网站，参加 2026 年全国青少年安全与应急科普创新大赛（人工智能方向）。

## 功能

- **4 个紧急救援场景**：火灾逃生（5关）、地震避险（4关）、溺水救援（5关）、烫伤处理（4关），共 18 个递进关卡
- **可拖动的安全小助手**：SVG 卡通角色，根据答题结果切换表情
- **CSS 动画场景**：火焰跳动、地震晃动、水波荡漾、蒸汽升腾
- **闯关徽章 + 知识口诀卡 + 可下载证书**
- **数据驱动架构**：新增场景只需添加数据对象

## 技术

纯 HTML/CSS/JS，无框架依赖。localStorage 持久化进度，Canvas API 生成证书。

## 运行

直接用浏览器打开 `index.html` 即可，或访问 GitHub Pages。
